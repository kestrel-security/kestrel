# Maintainers

Maintainers review and merge pull requests, triage issues, cut releases, and
make the decisions described in [`GOVERNANCE.md`](GOVERNANCE.md). Kestrel is
a personal open-source project. The maintainers below are the default owners
in [`.github/CODEOWNERS`](.github/CODEOWNERS).

| Name | GitHub | Areas |
|------|--------|-------|
| Jared Stewart | [`@jaredst3wart`](https://github.com/jaredst3wart) | Project lead; everything |

## Becoming a maintainer

Maintainers are contributors who have already been doing the work. There is no
application form; the usual path is:

1. A sustained record of merged contributions over several months: code,
   reviews, documentation, or issue triage all count.
2. Reviews that other contributors find useful, and familiarity with the
   decisions in [`docs/decisions.md`](docs/decisions.md).
3. An existing maintainer nominates you in a pull request that adds you to the
   table above. It is accepted by lazy consensus of the current maintainers
   (see [`GOVERNANCE.md`](GOVERNANCE.md)).

## Stepping down

A maintainer can step down at any time by opening a pull request that moves
them to an emeritus list here. A maintainer inactive for twelve months may be
moved to emeritus by the others, after asking them first.
